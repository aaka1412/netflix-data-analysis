# Netflix Data Analysis with Pandas

## 📌 Project Overview

This project is a beginner-friendly data analysis exercise using the Netflix Movies and TV Shows dataset from Kaggle. The objective was to practice the fundamentals of the Pandas library by exploring, cleaning, and analyzing real-world data.

Rather than focusing on advanced machine learning, this project emphasizes learning how to manipulate datasets, answer analytical questions, and extract meaningful insights using Python.

---

## 📂 Dataset

* **Dataset:** Netflix Movies and TV Shows
* **Source:** Kaggle
* The dataset contains information about Netflix titles, including:

  * Title
  * Type (Movie/TV Show)
  * Director
  * Cast
  * Country
  * Release Year
  * Rating
  * Duration
  * Genre
  * Date Added

## 📚 Concepts Practiced

Throughout this project, I practiced several fundamental Pandas operations, including:

* Reading CSV files
* Exploring dataset information
* Selecting rows and columns
* Filtering data using conditions
* Sorting values
* Handling missing values
* Finding unique values
* Using `value_counts()`
* Grouping data with `groupby()`
* Working with string operations
* Answering dataset-based analytical questions

## 📊 Sample Questions Solved

Some of the questions answered during this project include:

* How many Movies and TV Shows are available?
* Which country has the highest number of Netflix titles?
* What are the most common content ratings?
* Which release year has the most titles?
* Which directors have produced the most content?
* How many titles belong to each genre?
* Finding specific movies or TV shows using filters.
* Identifying missing values in the dataset.
